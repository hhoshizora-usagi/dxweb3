# dxweb3
DX Web のヘッダー・フッターのホバー演出アレンジ集です。
基本形（dxweb2 の一覧ページ）をもとに、ホバー時の動きを種類ごとに変えたサンプルをまとめています。

| No. | ディレクトリ | アニメーション | ハンチング | 対象 |
|--|--|--|--|--|
| 01 | 01-underline | 下線が左からスゥッと伸びる | Underline | ヘッダー・フッター |
| 02 | 02-fill | 背景がふわっと塗られる | Fill | ヘッダー・フッター |
| 03 | 03-glow | 文字がほんのり光る | Glow | ヘッダー・フッター |
| 04 | 04-expand | 文字間隔が広がる | Expand | ヘッダー・フッター |
| 05 | 05-lift | 要素が浮き上がる | Lift | ヘッダー・フッター |
| 06 | 06-reveal | 下線が右からスライドして現れる | Reveal | ヘッダー・フッター |

各ディレクトリの `index.html` をブラウザで開くと確認できます。
`index.html`（ルート）は一覧ページです。

## 使い方
- 各サンプルのヘッダー／フッターにマウスを乗せると演出が確認できます。
- 採用したい演出を教えてもらえれば、本番のサンプル（dxweb）に組み込みます。
